# Security Policy

## Supported Versions

This project is currently maintained on the latest main branch.

## Reporting a Vulnerability

If you discover a security issue involving authentication, API handling, AI provider integrations, secrets exposure, or user data handling, please report it privately instead of opening a public issue.

Recommended report contents:

- vulnerability summary
- affected component
- reproduction steps
- potential impact
- mitigation suggestions

## Security Engineering Principles

- no secrets committed to source control
- environment-based configuration only
- principle of least privilege
- dependency hygiene
- validated API inputs
- secure authentication flows
- defensive error handling
